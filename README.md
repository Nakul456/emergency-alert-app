# 🚨 CareWave – Emergency Alert Application

CareWave is a mobile-based Emergency Alert Application developed using **React Native (Expo)**. The application helps users quickly send SOS alerts and share their live location with trusted emergency contacts during emergencies.

This project was developed as a Final Year Engineering Project with the goal of improving public safety through real-time communication and location tracking.

---

## 📱 Features

- 🚨 One-Tap SOS Emergency Alert
- 📍 Real-Time Live Location Sharing
- 👥 Emergency Contact Management
- 🌙 Dark & Light Theme Support
- 🔐 User Authentication
- 📡 REST API Integration
- 📲 Cross-Platform Support (Android & iOS)

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Nakul456/emergency-alert-app.git
```

### Navigate to Project

```bash
cd emergency-alert-app
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npx expo start
```

### Run Android

```bash
npx expo run:android
```
